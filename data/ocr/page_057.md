# MISSIONS

Before you can wage war in a game of Warhammer 40,000, you must first select a mission. The Core Rules include a single mission – Only War – that is ideal to get the action started quickly. Others can be found elsewhere in this or other books, or you could play a mission of your own creation. If you and your opponent can’t agree which mission to play, you must roll off, and the winner decides.

      <h3>DECLARE BATTLE FORMATIONS</h3>
      <p>In the order stated below, both players now secretly note down:</p>
      <ul>
        <li>Which of their Leader units will start the battle attached (they must specify which Leader unit is attached to which Bodyguard unit).</li>
        <li>Which of their units will start the battle embarked within TRANSPORT models (they must specify which units are embarked within which models).</li>
        <li>Which of their units will start the battle in Reserves (including Strategic Reserves).</li>
      </ul>
      <p>When both players have done so, they declare their selections to their opponent.</p>

      <h3>CREATE THE BATTLEFIELD</h3>
      <p>Each mission will include details of the size of the battlefield that you will need. Each mission will also instruct you if any terrain features or objective markers must be set up, and will provide details of where to set them up. Otherwise, it is assumed you are using the guidelines on pages 49-52 to create your battlefield. If you are using a battlefield that is a different size or shape to those guidelines, you will need to adjust distances, and the location of deployment zones, objective markers and terrain features, in an appropriate way.</p>
